# Maintenance Slow-Wave Analysis

This folder contains the sustained maintenance-period amplitude analysis and its robustness assessment.

## Suggested order

1. `STEP09B3_MAINTENANCE_SLOWWAVE_N22_PATHFIX.m`  
   Main N=22 maintenance slow-wave analysis.

2. `STEP09D_MAINTENANCE_SLOWWAVE_ROBUSTNESS.m`  
   Robustness analysis for the maintenance slow-wave result.

## Dependency

The main slow-wave script uses outputs generated by:

`../erp_analysis/STEP09A2_CONDITION_ERP_WINDOWS_N22_ROIFIX.m`

## Interpretation

The maintenance slow-wave result is a sustained maintenance-period amplitude effect. It should not be framed as a classical sensory ERP component.
